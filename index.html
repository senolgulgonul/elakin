Elakinv1.2

Train a tiny language model on your own text, and watch every step.

Large language models are built from the same pieces you’ll see here: tokens, embeddings, attention and a training loop that nudges millions of numbers. This one has about twelve thousand of them, small enough to look at.

The name comes from e, l, a, k, i, n: the first six letters Turkish children learn to read. The Turkish sample text uses only those letters.

1Your text

The model will learn only from what you give it. A few pages of plain text in any language is plenty; more text gives better results but trains more slowly. The last 10% is kept aside to test the model on text it hasn’t seen.

2Tokens

A model can’t read letters. First the text is cut into pieces called tokens. Different models cut differently, and the choice matters: fewer, bigger tokens let a model see more text at once.

The whole text, cut five ways

The GPT-2 tokenizer here uses the same vocabulary as Hugging Face’s gpt2 tokenizer. Rare words and other languages break into many small pieces.

3Vocabulary

Our model uses the simplest tokenizer: one token per character. Every distinct character gets an ID number, and the text becomes a long list of numbers.

4Embeddings

An ID is just a label, so each one is swapped for a row of 32 numbers called an embedding. A second row says where the token sits in the sentence. The two are added together. Before training these numbers are random; training gives them meaning.

negativepositiveEach row is one character. The 32 columns are the 32 numbers of its embedding, not positions in the sentence.

5Attention

Attention lets each character gather information from the characters before it. Every position makes a query (what am I looking for?), a key (what do I contain?) and a value (what do I pass on?). Queries are compared with keys to decide how much of each value to take.

weights = softmax( Q · Kᵀ / √32 ), with future positions hidden

Rows are the character doing the looking; columns are the characters it can look at. Choose a row to see what that position pays attention to and what it predicts comes next. Right now the model is untrained, so the pattern is noise. Come back after step 6.

6Training

Training shows the model random 32-character windows of your text. At every position it guesses the next character. The loss measures how surprised it was by the right answer. After each batch, every number in the model moves a little in the direction that would have made the loss smaller.

8Generate

To write, the model predicts odds for the next character, picks one, adds it to the text and repeats. Temperature reshapes the odds: low is safe and repetitive, high is surprising and messy.
